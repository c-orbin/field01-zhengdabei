# 黑白图表语言规范

> FIELD / 01 备赛资料。一页只讲一件事。

## 1. 先写标题，再选图

图表标题应直接表达发现：

- 不写：“用户满意度分析”
- 改写：“高信息透明度将支付意愿提升 18%”

## 2. 图形选择

| 任务 | 首选图形 | 避免 |
|---|---|---|
| 比较类别 | 条形图 | 复杂 3D 饼图 |
| 时间变化 | 折线图 | 无时间顺序的柱堆叠 |
| 构成 | 堆叠条、华夫图 | 过多扇区饼图 |
| 分布 | 点图、箱线图 | 只报告平均数 |
| 属性优先级 | 点阵图、斜率图 | 无刻度雷达图 |
| 群体差异 | 小多图 | 叠满样本的散点图 |

## 3. 黑白层级

- 黑色：主结论与关键系列
- 深灰：次要比较
- 浅灰：背景或参考
- 白色：留白，不是另一种数据层

用线型、形状、直接标签和透明度区分系列。不要依赖颜色。

## 4. 信息减法

- 删除无意义的网格线与边框。
- 数值轴从零开始；截断时明确标志。
- 小数点精度不超过证据需要。
- 直接标注样本量、单位与显著性。
- 在脚注给出方法、样本与数据来源。

## 5. 人群 × 情境矩阵

每个格子代表一个“谁在何时使用”的组合，适合发现被平均数掩盖的机会。

### 输出内容

1. 人群细分：高活跃 / 高意愿 / 高流失风险
2. 情境分类：日常 / 应急 / 社交 / 礼赠
3. 格子大小：样本占比或市场规模
4. 格子标记：机会值、冲突点、置信区间

### 答辩讲法

先说最值得行动的格子，再解释为什么另一个看似较大的格子不是优先项。让策略判断与证据同时出现。
